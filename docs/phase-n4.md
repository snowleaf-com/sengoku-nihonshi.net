# Phase N4 — 戦争・占領

目的: **隣接国を攻め、守備または城壁を破り、占領できる**ようにする。  
式の詳細は [`net-spec.md`](./net-spec.md)。全体は [`roadmap.md`](./roadmap.md)。

## 完了条件

- [x] **戦争**（隣接の敵・中立のみ。自国不可）
- [x] 守備武将がいれば対武将、いなければ対城壁（城壁 str=30 / 訓練=60）
- [x] 占領で `provinces.house_id` 移譲、城壁戦勝利時は城壁 0
- [x] 建国後 36 ヶ月の戦争禁止（攻守双方。中立は常に可）
- [x] `houses.founded_turn`（旗揚げ時の `turn_index`）
- [x] 出来事 `kind=war` の戦報
- [x] 貢献 +20・武勇 EX +1（勝敗問わず）
- [x] テスト（`resolveBattle` は rng 注入で決定的）

## やらない

- 部隊システム・装備補正の本格移植
- 会議室（→ N5）

## 戦況ログ

`resolveBattle` は各ラウンドの与ダメージ・残兵を `log` に残す。  
攻撃側のコマンド結果と防衛側の個人結果に【戦況】を付ける（20行超は先頭・末尾を残して中略）。  
全国ニュースはラウンド数つきの要約のみ。
