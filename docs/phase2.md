# Phase 2

目的: **年月が進み、コマンドを予約して内政できるようにする**。

## 仮決め

- 開始: **1467年1月**
- 1ターン = **1か月**
- 実時間間隔: 当面 **60秒**（公開は 30分想定）
- **1月 = 税金（金） / 7月 = 年貢（米）**
- 技術は後回し

- [x] 選択UIに ↑↓（パワプロ風）

## UX

```text
Hub
  年月・次ターン
  能力 / 金米兵 / 農商民忠
  コマンドカード（効果の矢印つき）→ 予約
  予約一覧（取消可）
  → ターン進行で1件消化
```
