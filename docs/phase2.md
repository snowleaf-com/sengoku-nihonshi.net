# Phase 2

目的: **年月が進み、コマンドを予約して内政できるようにする**（ターン基盤）。

> **方針変更:** 以降のゲームルールは三国志.NET原本に寄せる（令制国マップは維持）。  
> 全体計画は [`roadmap.md`](./roadmap.md)。この文書の内政5種は **暫定**で、N1 で NET内政に置換する。

## 仮決め

- 開始: **1467年1月**
- 1ターン = **1か月**
- 実時間間隔: 当面 **60秒**（公開は 30分想定）
- **1月 = 税金（金） / 7月 = 年貢（米）**
- 技術は後回し → N1

## 完了条件（ブランチ時点）

- [x] `game_state`（年月・次ターン時刻）
- [x] 都市に民忠、武将に米と能力EX
- [x] コマンド予約キュー
- [x] 内政コマンド（暫定）: 開墾 / 市立て / 稽古 / 政務 / 米施し
- [x] 選択UIに ↑↓（パワプロ風）
- [x] ターン進行で先頭コマンド消化
- [x] 税金・年貢
- [x] Cron（毎分）＋開発用手動進行

## UX

```text
Hub
  上: 年月・次ターン（全体）
  左: 自身 / 都市 / 国
  中: 全国地図 → 下に出来事ログ
  右: コマンド予約
```

予約上限: **100**（N1 で原本寄り 24 に寄せる想定）
操作の基本: **枠を選ぶ → コマンドを選ぶ**

出来事ログ: ターン進行・内政・税収年貢を記録。戦・飢饉・一揆は kind のみ先置き。

## やらない（続き → roadmap N1〜）

- NET式の農業/商業/城壁、貢献、EX10
- 徴兵・訓練・移動・戦争
- 会議室・手紙・国法（N5）
- ドラッグ並べ替え
- 不在時自動ループ（削除対策）
