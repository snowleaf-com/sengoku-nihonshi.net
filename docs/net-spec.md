# 三国志.NET 仕様メモ（N1 抜粋）

参照: https://github.com/runtBlue/sangokushi-NET.original  
数値の正は原本。この文書は移植用の要約。

## 定数（index.ini）

| 名前 | 値 | 意味 |
|------|-----|------|
| `$MAX_COM` | 24 | 先行入力枠 |
| `$NOU_MAX` | 30000 | 農民上限 |
| `$LANK` | 500 | 階級アップに必要な階級値 |
| 開始年 | 180（原本） / 1467（本プロダクト） | 年号だけ差し替え |

## 能力 EX

- 内政系成功 → 知EX +1（農業・商業・城壁・技術）
- 米施し成功 → 人望EX +1（徳望EX）
- **EX 10 で対応能力 +1**（余りは持ち越し）

## 内政コマンド（exe_com）

共通: 成功時 **貢献 +30**。金/米不足時は不実行（ログのみ）。

### 農業 / 商業 / 城壁 / 技術

コスト: 金 50

```
gain = int( (知力 + 書籍補正) / 20 + rand(知力 + 書籍補正) / 40 )
```

- 農業 → 農業値（上限あり）
- 商業 → 商業値（上限あり）
- 城壁 → 城壁（上限あり）
- 技術 → 技術（上限 999）。書籍補正は当面 0

### 米施し

コスト: 米 50

```
gain = int( 人望 / 20 + rand(人望) / 40 )
民忠 = min(100, 民忠 + gain)
```

## 1月・7月

### 給与（1月=金） / 俸禄（7月=米）

家単位の総額:

```
# 1月
ksal += int(商業 * 8 * 農民 / 10000)  # 支配下の各国

# 7月
ksal += int(農業 * 8 * 農民 / 10000)
```

武将取り分:

```
kadd = int( ksal * 自分の貢献 / 家の貢献合計 + 貢献 * 1.3 )
cap  = 1000 + min(20, floor(階級値 / 500)) * 150
支給 = min(kadd, cap)
```

その後: `階級値 += 貢献`、`貢献 = 0`。  
階級値が閾値を跨いだら武勇/知略/統率のいずれか +1（ランダム）。

### 民忠による人口

1月・7月のみ（相場変動と同タイミング）:

```
民忠 >= 50: 農民 += max(500, int(80 * (民忠 - 50)))  # 上限 NOU_MAX
民忠 <  50: 農民 -= int(80 * (50 - 民忠))            # 下限 0
```

## 移動（mode 20）

- 隣接都市のみ
- 成功: 所在を更新、統率EX +1
- 所属国がある場合のみ 貢献 +20

## 仕官（SHIKAN）

- 無所属（浪人）のみ
- 所在都市の支配国へ仕官
- 中立・既所属は不可

## 米売買（BUY）

- 予約時の相場を payload に保存して実行（原本どおり）
- 米を売る: `金 += int(量 * 相場)`、米を減らす
- 金を売る: `米 += int(量 * (2 - 相場))`、金を減らす
- 1回の上限 3000
- 成功時 知略EX +1

## 自国以外の制限

自国以外（浪人を含む）で実行できるのは **移動・仕官・何もしない** のみ。  
内政・売買は自国にいるときだけ。

## 相場変動（1月・7月）

```
50% で上昇: souba += rand(0..0.5) 相当 → 上限 1.2
50% で下降: souba -= … → 下限 0.8
```

## 徴兵（雑兵のみ・N3）

- 兵数上限 = 統率
- 金コスト = 人数 × 10
- 農民 -= 人数 × 5、民忠 -= floor(人数 / 10)
- 成功: 貢献 +10、武勇EX +1
- 徴兵時、訓練度 -= 人数（下限 0）

## 訓練（N3）

```
gain = int(統率/6 + rand * 統率/6)
訓練度 = min(100, 訓練度 + gain)
```

成功: 貢献 +15、統率EX +1

## 守備（N3）

- 兵 > 0 が必要
- 所在国の守備フラグを立てる（同国の他武将の守備は解除）
- 移動成功時は守備解除
- 成功: 貢献 +25、統率EX +1

## 毎月の兵糧（N3）

各ターン、兵 > 0 の武将:

```
米 -= 兵数
米 < 0 なら: 脱走 = min(兵, -米)、米 = 0、兵 -= 脱走
兵が 0 になったら守備解除
```
