# 三国志.NET 仕様メモ（N1 抜粋）

参照: https://github.com/runtBlue/sangokushi-NET.original  
数値の正は原本。この文書は移植用の要約。

## 定数（index.ini）

| 名前 | 値 | 意味 |
|------|-----|------|
| `$MAX_COM` | 24 | 先行入力枠 |
| `$NOU_MAX` | 30000 | 農民上限 |
| `$LANK` | 500 | 階級アップに必要な階級値 |
| 開始年 | 180（原本） / 1467（本プロダクト） | 年号だけ差し替え |

## 能力 EX

- 内政系成功 → 知EX +1（農業・商業・城壁・技術）
- 米施し成功 → 人望EX +1（徳望EX）
- **EX 10 で対応能力 +1**（余りは持ち越し）

## 内政コマンド（exe_com）

共通: 成功時 **貢献 +30**。金/米不足時は不実行（ログのみ）。

### 農業 / 商業 / 城壁 / 技術

コスト: 金 50

```
gain = int( (知力 + 書籍補正) / 20 + rand(知力 + 書籍補正) / 40 )
```

- 農業 → 農業値（上限あり）
- 商業 → 商業値（上限あり）
- 城壁 → 城壁（上限あり）
- 技術 → 技術（上限 999）。書籍補正は当面 0

### 米施し

コスト: 米 50

```
gain = int( 人望 / 20 + rand(人望) / 40 )
民忠 = min(100, 民忠 + gain)
```

## 1月・7月

### 給与（1月=金） / 俸禄（7月=米）

家単位の総額:

```
# 1月
ksal += int(商業 * 8 * 農民 / 10000)  # 支配下の各国

# 7月
ksal += int(農業 * 8 * 農民 / 10000)
```

武将取り分:

```
kadd = int( ksal * 自分の貢献 / 家の貢献合計 + 貢献 * 1.3 )
cap  = 1000 + min(20, floor(階級値 / 500)) * 150
支給 = min(kadd, cap)
```

その後: `階級値 += 貢献`、`貢献 = 0`。  
階級値が閾値を跨いだら武勇/知略/統率のいずれか +1（ランダム）。

### 民忠による人口

1月・7月のみ（相場変動と同タイミング）:

```
民忠 >= 50: 農民 += max(500, int(80 * (民忠 - 50)))  # 上限 NOU_MAX
民忠 <  50: 農民 -= int(80 * (50 - 民忠))            # 下限 0
```

## 語彙対応
