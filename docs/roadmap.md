## レイアウト方針（任せる前提の約束）

Hub は常にこの骨格を崩さない。

```text
┌─────────────────────────────────────────────┐
│ 年月・次ターン・（開発用）手動進行            │
├──────────┬──────────────────┬───────────────┤
│ 自身     │ 全国地図         │ コマンド予約  │
│ 所在国   │ 出来事 (news)    │ 結果 (result) │
│ 家       │                  │               │
└──────────┴──────────────────┴───────────────┘
```

- N5 の会議室・手紙は **第2レイヤ**（タブ / モーダル / `/game/house` など）
- カード過多にしない。地図とコマンドが主役
- モバイルは縦積み（地図 → ステータス → コマンド）

## マージ戦略

1. **今すぐ:** Phase2 ブランチは「ターン基盤」として価値がある。N1 着手前に main へ載せるか、N1 と同じ PR にまとめるかを選ぶ
2. **推奨:** N1（式合わせ）まで一気にやってから main へ。独自内政を main に長く残さない
3. 各 Phase は PR を分ける（N1 / N2 / …）。N5 は遊べる状態（N4後）でまとめてよい
