## レイアウト方針

Hub は常にこの骨格を崩さない。

```text
┌─────────────────────────────────────────────┐
│ 年月・次ターン・（開発用）手動進行            │
├──────────┬──────────────────┬───────────────┤
│ 自身     │ 全国地図         │ コマンド予約  │
│ 所在国   │ 出来事 (news)    │ 結果 (result) │
│ 家       │                  │               │
└──────────┴──────────────────┴───────────────┘
```

- N5 の会議室・手紙は **第2レイヤ**（`/game/house` など）
- カード過多にしない。地図とコマンドが主役
- モバイルは縦積み（地図 → ステータス → コマンド）
