## 背景

1. 1回で3系統まとめて上がりすぎる
2. 上がったように見えて上限が戻る不具合
3. 知略依存だと武官の救済にならない
4. 都市ごとに普請で伸ばせる上限を決めたい

## 方針（採用）

| 項目 | 内容 |
|------|------|
| 不具合 | 初期投入以外で上限をマスターへ戻さない |
| 上げ方 | 農業 / 商業 / 城壁の **1系統選択** |
| 能力 | **武勇**（`max(8, netStatGain(buyu))`）。EX も武勇 |
| 名前 | **普請**のまま。説明に「武勇で効果」と書く |

### 都市別の普請上限（設ける）

**普請で伸ばせる天井は都市ランクごとに設ける。** 全国一律の巨大ハードキャップには戻さない。

たたき台（数字は実装時に調整。#33 の初期上限スケールと矛盾しないこと）:

| ランク | 普請で伸ばせる上限の考え方 |
|--------|----------------------------|
| 都市 | 初期上限に近い／伸びしろ小 |
| 中都市 | その中間 |
| 大都市 | 伸びしろ大 |

港はランクではなく属性なので、普請天井の軸には使わない（港ボーナスを足すなら別途決める）。

実装順:

1. 本PR: 不具合修正・1系統選択・武勇依存（天井はまだ付けない）
2. **続きPR: 都市ランク別の普請天井**（本 Issue の残り）
