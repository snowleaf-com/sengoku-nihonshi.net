## 背景

1. 1回で3系統まとめて上がりすぎる
2. 上がったように見えて上限が戻る不具合
3. 知略依存だと武官の救済にならない
4. 都市ごとに普請で伸ばせる上限を決めたい

## 方針（採用）

| 項目 | 内容 |
|------|------|
| 不具合 | 初期投入以外で上限をマスターへ戻さない |
| 上げ方 | 農業 / 商業 / 城壁の **1系統選択** |
| 能力 | **武勇**（`max(8, netStatGain(buyu))`）。EX も武勇 |
| 名前 | **普請**のまま。説明に「武勇で効果」と書く |

### 都市別の普請上限（設ける）

**普請で伸ばせる天井は都市ランクごとに設ける。** 全国一律の巨大ハードキャップには戻さない。

採用値は、マスターから求めたランク補正済みの**初期上限**に対する倍率（端数切り捨て）。現在の上限を基準にすると普請のたびに天井が増えるため、初期値を基準に固定する。

| ランク | 初期上限からの伸びしろ | 農業Bの例（初期上限 → 天井） |
|--------|----------------------|--------------------------------|
| 都市 | +10% | 750 → 825 |
| 中都市 | +15% | 787 → 905 |
| 大都市 | +20% | 825 → 990 |

初期の S/A/B/C の違いを残し、都市ランクの差を急激に拡大しない設定で開始する。各都市・各系統で値が異なり、天井到達までの実行回数は武勇に依存する。

- 天井直前は残りの分だけ上げる。費用は通常どおり金80（最低効果8より小さくなる場合もある）
- 天井以上では失敗とし、金・貢献・国貢献・EX は動かさない。予約は既存の失敗処理で消化する
- 導入前に天井を超えている都市は、現在値・上限とも減らさない。追加の普請のみ止める
- 通常の内政は、保持している上限まで引き続き可能
- DB の補正や migration は行わず、天井をマスターから計算してコマンド実行時に判定する
- 都市画面に各系統の天井、普請の対象選択に現在の上限／天井を表示する。到達済みの対象は選択不可にし、すべて到達済みなら入力ボタンを無効にする
- 入力後に他の武将の普請で天井へ到達する場合もあるので、実行時の判定を正とする

港はランクではなく属性なので、普請天井の軸には使わない（港ボーナスを足すなら別途決める）。
