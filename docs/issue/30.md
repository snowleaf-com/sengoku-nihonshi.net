# Issue #30 — Wrangler → Cloudflare `cf` CLI

- Issue: https://github.com/snowleaf-com/sengoku-nihonshi.net/issues/30
- 実装: [`../impl.md`](../impl.md)（Slice T）

## 背景

Cloudflare は **`cf` を Wrangler 後継**としてオープンベータ投入（2026-09）。  
ベータ終了後は Wrangler 最終メジャーが `cf` へ誘導し、その後 **18ヶ月メンテ**。早めに方針だけ固定し、着手はベータの安定を見てよい。

参照: [Introducing cf](https://blog.cloudflare.com/cloudflare-cf-cli-launch/)

## 現状

- `wrangler`（scripts / CI / typegen / D1 migrate / secret）
- `wrangler.jsonc`（production / staging・D1・cron・routes）
- 既に `@cloudflare/vite-plugin` 利用 → `cf migrate` 向き

## 方針

- 急がない。staging で十分試してから production
- クリーンな tree で `cf migrate`（必要なら先に `--dry-run`）
- `cloudflare.config.ts` へ。**staging の routes 空**（本番ドメイン奪取防止）を必ず維持
- scripts・`docs/development.md`・CI を `cf` ベースに更新
- Passkey・D1 migrate・deploy・cron を local / staging で確認
- secret（`ADMIN_SECRET` 等）の手順も合わせて書き換え
- 問題なければ `wrangler` 依存と旧設定を整理（しばらく共存でも可）
