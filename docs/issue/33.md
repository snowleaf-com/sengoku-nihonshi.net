# Issue #33 — 戦国日本史NET 魔改造

- Issue: https://github.com/snowleaf-com/sengoku-nihonshi.net/issues/33
- 実装: [`../impl.md`](../impl.md)（Slice E1〜E3 / F / G / H）
- 重複: [#28](./28.md) の盤面・普請は、数値とアイコンの正をこの文書にする

## 背景

三国志NETの単純さを残したまま、シーズンごとに違う戦国史になるようにしたい。  
操作を増やすのではなく、**地図を見る理由・都市を取る理由・国で相談する理由** を増やす。

## 現状

- 令制国は人口・農・商・城の S/A/B/C ティアで初期値が違う。プレイヤーに見える「大都市 / 中都市 / 都市」はない
- 隣接は陸の8方向のみ。港・海路・水軍はない
- 災厄（いなご・洪水・疫病・豊作・地震・好景気）は1月・7月に全国一律である
- 国家方針・家風・兵站・包囲・従属はない
- 役職は当主・軍師・大将・家臣。権限は任命と、戦争・内政のコマンド自体は誰でも出せる

## 方針

設計原則は Issue のまま。**毎ターン必須の操作、大量パラメータ、放置即死は足さない。**  
家風は国家方針と重複するので **作らない**。包囲・従属は将来（Slice H）。

### 進める順

1. **E1** 都市ランク（3段階）とマップアイコン、港は錨マークだけ
2. **E2** 港同士の海路侵攻
3. **E3** 水軍兵
4. **F** 国家方針（1国1つ、効果はおおよそ +10%、変更は半期間隔）
5. **G** 都市特性・簡易兵站・役職の補助権限
6. ランダムイベントは **既存災厄を拡張**する。別系統は作らない

#28 の人事（C）・宣戦（D）は、この盤面より先でも後でも独立に進められる。推奨は **B の次に E1**。

### 都市ランク（E1）

見た目と上限の差は付ける。**大都市を取れば勝ち、にはしない**（上限差は小さめ。収入式の支配項にはしない）。

ランクは人口・農業・商業・城壁・徴兵余地の **上限側** にだけ効かせる。初期値の S/A/B/C はそのまま土台にしてよい。

アイコンはランクで形を変える。色だけでは区別しない。

| ランク | シルエット |
|--------|------------|
| 大都市 | 大きな城郭 |
| 中都市 | 小さな城 |
| 都市 | 家並み・田 |

港はランクではなく属性。大・中・都市のどれにも付けられ、アイコン右下に錨。

#### 初期の大都市（畿内に寄せない）

次の10国を大都市の初期値にする。中都市は「人口 A または商業 A」のうち大都市でない国。残りは都市。

| 地方 | 大都市 |
|------|--------|
| 東北 | 陸奥 |
| 関東 | 武蔵、相模 |
| 東海 | 駿河、尾張 |
| 北陸 | 越前 |
| 畿内 | 摂津（山城・大和は中都市に留める） |
| 中国 | 安芸 |
| 九州 | 肥前、薩摩 |

### 海路（E2）

陸路に加え、**港属性を持つ国同士**だけ非隣接でも侵攻できる。コストは陸路より重くする（消費の具体倍率は未決だが、陸路の単純コピーにはしない）。

初期接続:

```text
出羽 — 能登 — 越前
伊豆 — 志摩 — 紀伊 — 淡路 — 阿波 — 讃岐 — 伊予
淡路 — 長門 — 筑前 — 肥前 — 薩摩
安房 — 上総は陸路のまま（安房は港、上総は港にしない）
```

港にする国: 上の接続に出る国全部（上総は除く）。土佐は港にするが、初期接続は伊予のみ。

### 水軍兵（E3）

- 新兵種は水軍兵だけを先に足す。#32 の多兵種はその後
- 陸戦は弱い、海路戦は強い
- 徴兵は港にいるときだけ
- **通常兵でも海路侵攻はできる**（弱い）。水軍必須にはしない

### 国家方針（F）

国につき1つ。効果は単一ボーナス（商業・農業・軍事・防衛・水軍・城壁・調略のいずれか +10% 程度）。  
変更は 1月/7月境界まで固定。家風は作らない。

### 中優先（G）

- 都市特性は「その都市を取る理由が1つ増える」まで。山城 / 水城 / 商業 / 農業 / 金山。港は特性ではなく E1 の属性
- 兵站は飛び地かどうかだけ。複雑な補給線は作らない。飛び地は兵糧消費増と戦闘力低下
- 役職は補助。不在だと国が止まる権限は付けない

### イベント

既存の全国災厄を残す。追加するなら、民忠が低いと凶作・一揆側、港だと交易側、に **既存抽選の重みを変える** ところまで。新メニューは増やさない。
