# Issue #33 — 戦国日本史NET 魔改造案（計画）

- Issue: https://github.com/snowleaf-com/sengoku-nihonshi.net/issues/33
- 実装: [`../impl.md`](../impl.md)（Slice **E** と **F**。**#28** の盤面・戦争項目と重なる部分は E を正とし、本 Issue は中長期の設計原則と追加案の置き場）

## 背景

MVP（N6）とポスト MVP の UI／人事（[`28.md`](./28.md)）を進めつつ、**三国志 NET 並みの操作量**のまま「毎シーズン違う展開」を生む拡張の全体像を Issue にまとめたもの。

コンセプトの要:

> **操作を増やさず、選択と展開を増やす**

国・都市・地理・シーズンで差が出るようにし、パラメータや毎ターン操作は増やさない。

|------|------|

## 方針

### 設計原則（Issue より — 実装判断の共通ルール）

**避ける:** 毎ターン必須操作、パラメータ乱立、初見不可、最適解暗記、古参だけ有利、放置即死要素の過多。

**増やす:** 地図を見る理由、国で相談する理由、都市の奪取・防衛理由、兵種選択、シーズン差、弱小国の選択肢。

### #28 / impl Slice との役割分担

| テーマ | 先に触る Slice | 本 Issue で足すもの |
|--------|----------------|---------------------|
| UI 洗練 | **A**（ほぼ完了。ロゴ・ DS は残） | アイコン徹底は A と **E/F** の両方 |
| 昇進・貢献・相場 | **B** | — |
| 下野・登用文・追放 | **C** | — |
| 宣戦・奇襲 | **D** | 海路侵攻は **F**（陸路 D と別コマンド／コスト設計） |
| 都市ランク・湊・普請・期 | **E** | ランク別 **シルエットアイコン**、港 **錨オーバーレイ**、海路グラフ |
| 国家方針・水軍・イベント拡張 | **F**（新設） | 単純な % 補正、水軍兵、イベント池 |

**推奨順（#28 を崩さない）:** いまの [`impl.md`](../impl.md) どおり **A 残 → B →（普請小さく）→ C → D → E の土台 → F 高優先**。  
**T**（`cf` CLI）は引き続き独立。

### Issue 本文の各案 — 採用の向き

1. **都市ランク**（大／中／都市）— 上限（人口・農商・城壁・徴兵）を段階化。**大都市独占で決着しない** 幅に抑える。→ Slice **E** + **F**（データ・式）。
2. **都市アイコン** — ランクは **形**、港は **右下錨**、色だけで区別しない。→ **F**（`ProvinceMap` / アセット）。
3. **港・海路** — 港属性都市間の非隣接侵攻ルート。→ **F**（隣接 [`adjacency`](../src/domain/province/adjacency.ts) とは別グラフ）。
4. **水軍兵** — 陸戦弱・海路戦強。港での徴兵可否は **未決** のまま小さく試す。→ **F**。
5. **都市特性** — 少数（山城・水城・商業・農業・金山・港）。「取る理由が 1 つ増える」程度。→ **F** 中優先。
6. **国家方針** — 1 国 1 方針、+10% 程度の単純効果、変更は低頻度。→ **F** 高優先。
7. **家風** — 建国時固定。**国家方針と役割が重なれば実装しない**（Issue 記載どおり）。→ 将来（**F** 低）。
8. **簡易兵站** — 前線と本国の連結のみ。飛び地で兵糧・戦力ペナルティ。→ **F** 中。
9. **包囲戦** — 強攻 vs 時間かけて城下ろし。→ 将来（戦闘 UI 影響大）。
10. **ランダムイベント** — 既存災厄を拡張し、都市状態で重み付け。→ **F** 高（既存 `disaster` / events 系に統合）。
11. **従属国** — 弱小存続・勢力構造。→ 将来（外交・収入分配）。
12. **役職拡張** — 水軍奉行・城代など **補助権限**（非ログインで国が止まらない）。→ **F** 中。
