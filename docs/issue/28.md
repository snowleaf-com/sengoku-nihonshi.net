## 背景

MVP（N6）後のプレイ感・UI・ルール穴のメモが Issue に溜まっている。  
「とにかく UI」が強いので、機能追加より先に Hub／コマンド周りを整えるのが投資対効果が高い。

## 現状

| 項目 | 状態 |
|------|------|
| 浪人 / 仕官 / 登用（即時・成功率） | あり |
| 相場のターン変動 | あり（都市差の強化はこれから） |

| 昇進の専用お知らせ | 薄い／なし |

## 方針

### 進め方

1. **UI（Slice A）** を先に
2. **経済・昇進通知（B）**
3. 合戦向きの暇対策として **普請は早めに小さく** 入れてもよい
4. **人事（C）→ 宣戦・奇襲（D）→ 盤面・期（E）**

### UI / UX

- カード内スクロールはやめ、展開／折りたたみへ
- コマンドの「開く」と「編集」は一本化
- キュー多件時も選択肢が見える（固定フッター／シート等）
- 実行結果はコマンド欄から外し、「あなたの結果」へ
- ヘッダーは石高・金ではなく **次ターンまで** と **次コマンド**
- コマンド／知らせに実行（発生）予定日時
- 「名称」→「名将一覧」、「会議室」→「作戦会議」系。部隊は作戦会議へ。掲示板は Hub に残す
- 我が国の将一覧: 能力・滞在国・予定コマンド（〜4）を次実行が近い順
- デザインシステム・ロゴ・トースト・アイコン徹底表示
- ターン進行の運用は staging / admin 中心に整理

### 経済・貢献

- 鍛錬だけでは税金／年貢の対象にしない
- 半期間（1–6 / 7–12）に国貢献がなければ次の支給なし
- 内政・軍事・守備・徴兵などを貢献扱い
- 階級アップは news / 個人結果で知らせる
- 相場は既存変動に都市ティア別の基準幅などを足す

### 人事

- **下野**: 家離脱→浪人（当主は不可 or 後継必須）
- **登用文**: 提案→受諾／拒否→家臣化。即時登用と並存するかは実装前に決める
- **追放**: 当主・軍師が対象を浪人化

### 戦争

- **宣戦布告**を戦争の前段にする
- **奇襲**は宣戦なし侵攻可。消費倍やペナルティで帳尻

### 盤面・長期

- 都市ランク（大／中／都市）＋小アイコン。畿内偏重を避ける初期値
- 湊町: 港口同士は非隣接でも侵攻可（コストでバランス）
- 普請: 農業／商業／城壁の **Max** 上げ（値上げコマンドとは別）
- 第〜期・歴代統一国と武将スナップショットを名将一覧に残す
