### UI / UX

#### レイアウト方針（スマホ特化・PCも中央カラム）

参考: [ネココネ公式](https://nekoconne.com/?lang=ja) のような **画面の真ん中だけが縦長のアプリ枠**。左右は余白（または薄い地紋）で、中身はスマホと同じ幅で縦に積む。

| 項目 | 方針 |
|------|------|
| 正 | スマホ。PC向けの横広2カラム／3カラムは増やさない |
| PC | ビューポート中央に `max-width ≈ 430〜480px` のフレーム。中身はモバイルと同じ HTML／CSS |
| 背景 | フレームの外側は地色 or ごく薄いパターン。ゲーム本体はフレーム内だけ |
| コマンド | PC専用の横並びをやめて、スマホと同じタブ＋縦積みに寄せる |
| 下ナビ | フレーム内の下に常時表示。PCでも同じ。**画面切替の主役** |
| 地図 | フレーム幅に収める。マスを無理に横へ広げない |

#### フッターで即切替

下ナビは実装済みの **アプリのタブ切替** を維持する。

| タブ | 出すもの |
|------|----------|
| 地図 | 地図面（＋キュー要約など最小情報） |
| 自身 | ステータス・都市・自国など自分まわり |
| 結果 | 自身のコマンド結果フィードだけ |
| 知らせ | 全国系（仕官・戦争・災害・一揆など）だけ |
| コマンド | **タブではない。** どこからでもモーダルで開く |

方針:

- **1画面に1タブ。** 下を押したら即その面だけ見える（長いページをスクロールしない）
- 結果と全国知らせは別タブ（同居させない）
- 選択中のタブが分かる（ハイライト）。トップ（初期表示）はユーザーが選べる
- PCの中央カラムでも同じフッター・同じ切替。幅だけ違う
- 手紙・作戦会議などはサブページのまま。戻ったらさっきのタブに戻れるとよい

進め方（実装時）:

1. [x] `game-layout` を中央カラムのシェルで包む（max-width + margin:auto）
2. [x] Hub を「全部縦積み」から **タブで見せる面を切り替える** 構造にする

4. [x] コマンドシートの PC 横並びをやめ、縦積み／タブに寄せる

#### 個別

- カード内スクロールはやめ、展開／折りたたみへ
- コマンドの「開く」と「編集」は一本化
- キュー多件時も選択肢が見える（固定フッター／シート等）
- 実行結果はコマンド欄から外し、「あなたの結果」へ
- ヘッダーは石高・金ではなく **次ターンまで** と **次コマンド**
- コマンド／知らせに実行（発生）予定日時
- 「名称」→「名将一覧」、「会議室」→「作戦会議」系。部隊は作戦会議へ。掲示板は Hub に残す
- 我が国の将一覧: 能力・滞在国・予定コマンド（〜4）を次実行が近い順
- デザインシステム・ロゴ・トースト・アイコン徹底表示
- ターン進行の運用は staging / admin 中心に整理

### 経済・貢献

採用したルール（Slice B）:

- **貢献**（`merit`）は鍛錬を含む。1月・7月に階級値へ繰り込み、昇進の対象
- **国貢献**（`country_merit`）は鍛錬を除く。税金・年貢の按分だけに使う
- 国貢献が付くコマンド: 内政（農業・商業・城壁・技術・米施し）、所属ありの移動、徴兵、訓練、守備、戦争
- 半期間はいまのリセットと同じ。12月コマンドのあとが1月の税金、6月コマンドのあとが7月の年貢。その窓で国貢献 0 なら支給なし
- 階級が上がったら個人結果と全国の知らせ
- 相場は商業ティアごとに中心をずらした幅（B は 0.8〜1.2 のまま）

### 人事

- **下野**: 家離脱→浪人。当主は不可（実装済み）
- **登用文**: 提案→受諾／拒否→家臣化。即時登用と並存するかは実装前に決める
- **追放**: 当主・軍師が対象を浪人化
- **手紙**: いまは誰でも誰にでも送れる。滅亡後の浪人への声かけは、生きている国の当主・軍師が手紙で行う想定（登用文は将来の正式フロー）

### 戦争

- **領土0で即滅亡**: 全国ニュース。元家臣は所在を変えず浪人
- **帰順の礼**: 滅亡から12ヶ月以内に、領土を奪った家へ仕官／登用されると武勇・知略・統率それぞれ+10（憎しみで入りにくいので強めの特典）
- **宣戦布告**を戦争の前段にする
- **奇襲**は宣戦なし侵攻可。消費倍やペナルティで帳尻
