# Issue #32 — 開発用メモ

## 背景

プレイ中の操作感と、兵種を増やしたいメモ。ゲームの骨格（#28 / #33）より後でよい。

## 現状

- モバイルは Hub を縦積み。下部の常設ナビはない
- ターン間隔は staging 60秒 / production 1800秒（30分）。開始時刻はサーバー起動や進行に依存し、毎時00分・30分には揃っていない
- 階級名（重臣など）と家中役職（当主・軍師）は別。当主でも階級が重臣未満なら階級名が先に出る
- コマンドのパターン繰り返しはある。名前付きの定型は3枠ない
- 兵種は雑兵のみ。技術で兵種は増えない

## 方針

### ターン時刻（U）

- **世界イベント**（税金・年貢・災厄・「〜月になった」）の実時刻は、本番の30分間隔に合わせ **毎時00分と30分** にスナップする
- **個人のコマンド消化**は、その間隔のまま **登録した分** を維持する（13分登録なら 13分と43分）
- 10分グリッドは本番間隔が30分なので採用しない
- staging（60秒）はスナップしない。時刻合わせは production の運用

### 当主の表示（U）

- 家中役職が当主なら、階級名より **「当主」を優先**して見せる
- 軍師なのに階級が雑兵、は役職と階級が別であることの説明として残す。表示を無理に上げない

### コマンド定型（U）

- いまの繰り返しに加え、**名前付きパターンを3つ**保存できるようにする
- キュー100件の操作を増やしすぎない。既存の一括入力の延長にする

### モバイルフッター（U）

- Hub の骨格（地図・自身・コマンド）は崩さない
- 地図 / 自身 / コマンド / 知らせ、程度の **アイコンフッター** をモバイルだけに足す

### 兵種（M）

- 候補: 農兵、一般兵、護衛兵、弓兵、騎馬兵、鉄砲兵、連弩兵、神鬼兵
- **技術で解放**する。最初から全部は出さない
- #33 の水軍兵と役割が重なるので、**水軍の方針が閉じてから** 着手する
