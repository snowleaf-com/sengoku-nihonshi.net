# Phase 1.5

目的: **立ち回りを1つ選ぶと初期能力が出て、説明書なしで3能力だけ整えられる**ようにする。

## 完了条件

- [x] 能力: 武勇 / 知略 / 統率 / 徳望
- [x] 立ち回り: 合戦 / 内政 / 知略 / 統率
- [x] 入力は **武勇・知略・統率の3つ**（各 **5〜100**、合計 **150**）※古典NETと同じ幅
- [x] **徳望は立ち回り固定**（人望と同様、登録時に触れない）
- [x] 立ち回り変更で初期値が差し替わる（HTMX）
- [x] `/game` で能力表示

## UX

```text
名前 → 顔 → 立ち回り
           └ 武勇/知略/統率が初期表示 → 合計150で微調整（徳望は表示のみ）
         → 地図（建国/仕官）→ 戦国の世へ
```

| 立ち回り | 初期の振り | 徳望 |
|---|---|---|
| 合戦向き | 武勇・統率に寄せ、知略は下限 | 低 |
| 内政向き | 知略寄り（迷ったらこれ） | 高 |
| 知略向き | 武勇下限、知略・統率へ | 低〜中 |
| 統率向き | 統率最大寄り、知略は下限 | 中 |

## やらない

- 徳望の手動入力
- 「手動 / 自動」の二択
- 能力が効く内政・戦闘（→ Phase 2）
