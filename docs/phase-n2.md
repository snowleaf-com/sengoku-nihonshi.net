# Phase N2 — 移動と商人

目的: **隣接国へ動き、浪人は仕官でき、相場で米と金を換えられる**ようにする。  
式の詳細は [`net-spec.md`](./net-spec.md)。全体は [`roadmap.md`](./roadmap.md)。

## 完了条件

- [x] **移動**（隣接のみ。成功時 統率EX+1、所属ありなら貢献+20）
- [x] **仕官**（浪人のみ。所在国の支配家へ）
- [x] **米売買**（相場 `market_rate`、1回最大3000、知略EX+1）
- [x] 自国以外では移動・仕官のみ実行可
- [x] 1月・7月に相場が変動（0.8〜1.2）
- [x] コマンドに `payload`（移動先・売買量）
- [x] テスト

## やらない

- 武器・書籍購入（余裕があれば別PR）
- 戦争・徴兵（N3〜）
- 会議室（N5）
