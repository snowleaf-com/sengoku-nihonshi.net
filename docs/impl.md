対応順（2026-11-01、未対応 Issue 7件とコメント・現行コードを確認）:

1. **W / #40**: 占領後に攻撃者が移動しない不具合。最優先で独立修正

5. **E2 → E3 → M → F / #33・#32・#41**: 海路、水軍、技術で解放する兵種、国家方針。係数を決めて段階実装

**C / D** は未決を閉じてから独立して対応。**G → H** は後。**T / #30** は保留し、着手時に公式情報・互換性を確認する。既存 Issue 本文のベータ情報だけでは移行しない。

#28・#32・#33 は複数機能の親 Issue として残りだけを追跡する。#39 は修正済み部分と未実装の天井を区別し、天井まで検証してから完了判定する。
#33 の「操作を増やさず、選択を増やす」を優先する。家風は国家方針と重複するので作らない。
